# Crabbox Codex Defaults

Edit these files to set the default Codex setup for new crabboxes:

- `AGENTS.md` becomes `~/.codex/AGENTS.md` in the crabbox.
- `config.toml` becomes `~/.codex/config.toml` in the crabbox.

The New Crabbox sheet loads these files, then lets you edit either value for one
lease without changing the files here.
